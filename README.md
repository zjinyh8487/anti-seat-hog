# 防占座监测器 · Anti-Seat-Hog

用一块 **ESP32 + HX711 称重 + 人体红外** 判断座位上的「占座」行为：人走了但东西还留在座位上，超过设定时间就报警。
配套一个电脑端 **座位总览大屏**（网页），可以同时盯多个座位，通过 UDP 广播自动发现网络里的座位设备。

> 比赛项目 · 2026-11-08

---

## 它能做什么

| 状态 | 判断条件 | 表现 |
|---|---|---|
| 空闲 `empty` | 重量 < 0.5kg | 卡片绿色 |
| 有人使用 `seated` | 重量 > 0.5kg 且红外刚检测到动作 | 卡片蓝色，板载 LED 常亮 |
| 座上有物品 `object` | 重量 > 0.5kg 但红外已经安静 | 卡片黄色，LED 慢闪，大屏开始倒计时 |
| 占座告警 `hog` | 有物品持续超过阈值（默认演示 20 秒） | 卡片红色脉冲，电脑三声急响，标题变「⚠ N 个占座告警」，板载 LED 快闪，DFPlayer 循环播放报警音 |

其它功能：

- **手动去皮**（空座上点一下，重量归零）
- **清除报警**（东西还在但先消警）
- **停止播放**（报警保留，声音先停）
- **多座位**：每台设备叫 `seat-01`/`seat-02`…，大屏自动发现，不用手填 IP
- **掉线显示**：6 秒没心跳就标「离线」，不会假装还连着

## 硬件

| 元件 | 说明 |
|---|---|
| ESP32 DevKit（esp32doit-devkit-v1） | 主控，Wi-Fi |
| HX711 + 称重传感器（5kg 量程一般够用） | 压在座垫下 |
| HC-SR501 人体红外模块 | 判断「人是刚走还是根本没来」 |
| DFPlayer Mini + 小喇叭 + microSD | 报警音（可选，没有也能靠电脑提示音） |
| LED（板载 GPIO2） | 状态指示 |

### 接线

| 功能 | ESP32 引脚 |
|---|---|
| HX711 DT（DOUT） | GPIO18 |
| HX711 SCK | GPIO19 |
| 人体红外 OUT | GPIO23 |
| 板载 LED | GPIO2 |
| DFPlayer TX → 1kΩ → | GPIO16 |
| DFPlayer RX | GPIO17 |

DFPlayer 的 **VCC 尽量接 VIN/5V**（接 3V3 容易音量不足/播不出来），并且必须和 ESP32 **共地**。

## 快速开始

1. 打开 `anti-seat-hog.ino`，改最上面两行 Wi-Fi：
   ```c
   static const char* WIFI_SSID = "你的Wi-Fi名";
   static const char* WIFI_PASS = "你的密码";
   ```
2. Arduino IDE 选板子 `ESP32 Dev Module`，上传。
3. 板子上电后串口会打印 IP；浏览器打开 `http://<那个IP>/` 就能看到单台设备的网页。
   - 连不上 Wi-Fi 时，板子 25 秒后自己开热点 **`seat-01` / `12345678`**，IP 固定 `192.168.4.1`。
4. 电脑端大屏（Windows，需要 Python 3）：
   ```
   pc\run_dashboard_bg.cmd
   ```
   然后浏览器打开 <http://127.0.0.1:8899>。
   **手机**在同一个 Wi-Fi 下打开 `http://<电脑的IP>:8899`，页面自适应窄屏。

### 报警音

- **电脑提示音**：大屏右上角「🔔 提示音」，第一次点=解锁并打开（浏览器规定必须有用户点击才允许出声）。
- **板子喇叭**：microSD 卡要 **FAT32**，根目录放一个 **`0001.mp3`**（别用中文文件名，别用 flac）。DFPlayer 只认这种命名。

## 判定参数（`anti-seat-hog.ino` 顶部）

| 宏 | 含义 | 默认 |
|---|---|---|
| `W_OBJECT` | 超过多少算「座上有东西」 | 500 g |
| `W_HYST` | 回差，退出阈值 = W_OBJECT − W_HYST | 200 g |
| `DEBUG_FAST` | 1 = 演示模式，占座判定 20 秒 | 1 |
| `HOG_TIMEOUT_MS` | 有物品多久判占座 | 20 s(演示) / 10 min(正式) |
| `PIR_HOLD_MS` | 红外多久没动作算人走了 | 20 s(演示) / 120 s(正式) |

## 已知问题

- 称重模块偶尔会顶到量程极限（读数 ±8388607 或 0），这时读数作废：重插 HX711 的四根线、再做一次「重新去皮」。
- DFPlayer 在部分克隆板上 TX 走线接触不良，会导致收不到回包；固件里的 `mp3rx` / `mp3ack` 就是用来判断模块到底有没有在回话的。
